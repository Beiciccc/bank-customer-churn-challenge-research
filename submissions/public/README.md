# Public Submission Directory

This folder contains the curated submission CSVs used in public iteration logs.

Included files are the core runs and blend candidates from the full local experiment history, selected to keep the repository concise while preserving reproducibility:

- Baseline/first-phase runs (`run01`-`run19`).
- Regularization/cross-family follow-up candidates (`run20`-`run29`).
- Aggressive blend exploration (`run31_*`, `exp_*`, `rank_mix_*`).

Large local training artifacts (`.npy`, model binaries, full internal notebook dumps) are excluded from this repository and are intentionally not tracked.
